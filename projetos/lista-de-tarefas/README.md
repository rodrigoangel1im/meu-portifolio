# 📋 Lista de Tarefas

Aplicação web de gerenciamento de tarefas: adicionar, concluir e excluir itens, com persistência dos dados no navegador (`localStorage`). Projeto acadêmico do Bootcamp — versão 1.0.

## 📋 Descrição
Um gerenciador simples de tarefas com interface responsiva. As tarefas ficam salvas no `localStorage`, então são mantidas mesmo após fechar o navegador.

## 🛠 Tecnologias
- HTML5
- CSS3 (responsivo)
- JavaScript (DOM, eventos e LocalStorage)

## 💻 Como executar
```bash
git clone https://github.com/rodrigoangel1im/meu-portifolio.git
cd meu-portifolio/projetos/lista-de-tarefas
start index.html        # Windows — abre no navegador
```
> Não é necessário servidor: basta abrir o `index.html`.
