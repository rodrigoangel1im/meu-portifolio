# 🧮 Calculadora de IMC

Aplicação web simples que calcula o **Índice de Massa Corporal** a partir do peso e da altura, exibindo a classificação conforme a OMS. Projeto acadêmico do Bootcamp — versão 1.0.

## 📋 Descrição
O usuário informa peso (kg) e altura (m); o site valida os dados e mostra o IMC com a classificação correspondente (abaixo do peso, normal, sobrepeso e obesidade).

## 🛠 Tecnologias
- HTML5
- CSS3 (layout responsivo, variáveis e gradientes)
- JavaScript (validação e cálculo no DOM)

## 💻 Como executar
```bash
git clone https://github.com/rodrigoangel1im/meu-portifolio.git
cd meu-portifolio/projetos/calculadora-imc
start index.html        # Windows — abre no navegador
```
> Não é necessário servidor: basta abrir o `index.html`.
