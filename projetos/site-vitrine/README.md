# 🌐 Site Vitrine (Portfólio)

Página pessoal **responsiva** publicada via **GitHub Pages**. Serve como vitrine dos meus projetos e documentos. Projeto inicial do repositório — **versão 1.0** (tag `v1.0`).

## 📋 Descrição
Site de portfólio com seções de Início, Sobre, Projetos, Documentos e Contato. Foi a primeira versão do repositório e é a página publicada em `https://rodrigoangel1im.github.io/meu-portifolio`.

## 🛠 Tecnologias
- HTML5
- CSS3 (variáveis CSS, grid, media queries)
- JavaScript (menu responsivo)
- GitHub Pages (publicação)

## 💻 Como executar
```bash
git clone https://github.com/rodrigoangel1im/meu-portifolio.git
cd meu-portifolio
start index.html        # Windows — abre no navegador
```
Ou acesse a versão online: **https://rodrigoangel1im.github.io/meu-portifolio**
