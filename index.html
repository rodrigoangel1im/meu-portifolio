Segurança e boas práticas

Controles adotados para proteger o repositório, o histórico e os visitantes.

  • 2FA obrigatório na conta do mantenedor e para quem tem permissão de escrita.
  • Branch main protegida com Pull Request obrigatório, revisão e bloqueio de force-push.
  • Secret scanning e push protection para impedir o vazamento de tokens e senhas.
  • Dependabot semanal para manter as GitHub Actions atualizadas.
  • LGPD e privacidade: apenas dados profissionais já públicos, sem telefone ou endereço.

O status de cada controle (configurado no repositório ou pendente em Settings) está na política de segurança completa · Como reportar uma vulnerabilidade
